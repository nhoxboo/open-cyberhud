Bước 2: Cắm Cáp USB & Tiến Hành Nạp Trực Tuyến

Đang chọn bản build cho ESP32-2432S024 (CYD 2.4" Ngang 320x240). Kết nối cổng USB vào máy tính và bấm nút nạp.

💡 Mẹo nạp nếu gặp lỗi kết nối:
- Sử dụng trình duyệt Google Chrome hoặc Microsoft Edge trên máy tính.
- Nếu bấm Connect bị timeout: Nhấn giữ nút BOOT trên mạch, cắm cáp USB vào máy, rồi nhả nút BOOT để đưa MCU về chế độ nạp ROM.

Kết Nối Với HUD Qua Web Bluetooth Chưa kết nối

Bật Bluetooth trên máy tính/điện thoại, cấp nguồn OpenCyberHUD, sau đó bấm nút tìm thiết bị.
